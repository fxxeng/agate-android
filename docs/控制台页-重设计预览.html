改了什么

卡片墙 · 7~9 张同款卡等权重只留一个主状态区；连续信息改「分组 + 分隔线列表」
Hero 沿用 v44 深蓝渐变纯色表面 + 顶部 1px 高光，与纯黑主题统一
KPI 挤成一行 15sp 小字2×2 大数字网格，数字成为首屏主体
强调色大面积铺开只用于主按钮、活动点、关键数字；其余走中性灰阶
向导 / 崩溃 / 自检各占一张卡降级为 2px 色条 inline notice，不再抢焦点
入口卡各带标题 + 圆角 + 边框合并成一张「更多」列表，行高统一 44dp

落地范围（确认后才动代码）

· ConsolePage.kt：重排区块，Hero / KPI / 列表 / notice 四块
· ui/theme/Color.kt：只加表面层级 token，浅色档逐值不动
· 新组件：大数字网格与分组列表（可复用给额度、模型页）
· 不改数据源、不改刷新节奏、不改任何业务语义

切换上方按钮可对照现状。示例数值仅用于排版演示。确认这版方向后，我再按项目规矩出落地方案并改 app/ 代码；若想调整色板、字阶或保留某些现有卡片，直接说。
