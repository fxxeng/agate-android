取舍：为什么详情做成「折叠组」而不是全平铺

5 · 访问密钥「可用范围」补全

上游 keys.json：每把 Key 可单独限制可用提供商 + 可用模型，交集生效；被限制的 模型对这把 Key 表现为「不存在」（/v1/models 也看不到）。 内核已返回 allowedProviders / allowedModels 与两张候选表 （providers、modelsByProvider），客户端只需接上。

Key 可用范围 · 公司电脑
可用提供商留空 = 不限制
✓ CatPaw 4 ✓ CodeArts 2 Loomy 1 Qoder 1
可用模型候选跟着上面勾选走
✓ gpt-4o ✓ claude-sonnet-4 glm-5.3 deepseek-reasoner
没勾提供商时此项为空（还没有约束范围）；勾了几家就列这几家能收的全部对外名
两个都设时按交集生效：被限制的模型对这把 Key 表现为「不存在」， 提供它的家不在可用列表里时请求同样被拒。修改后立即生效；本程序自身会自动 使用第一把启用的 Key。
