在现有的「客户端所见清单 + 双视图 + 分组」骨架上，叠加对比分析里缺的信息 （可见性 / 来源 / 上下文·输出 / 能力徽章 / 别名），聚合与分组两个视角都保留。

内核已补「可见性」：从上游 data.agents[cli].models（官方 picker 名单）比对得出 shown / hidden；拿不到名单时不写该键（界面显示「—」，不谎报可见）。
其余数字全部来自 /api/models/manage：capabilities（六键生效值）+ capSources（每键来源）。
