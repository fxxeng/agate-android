### 生命周期

- **快照轮询**（5s，`startPolling/stopPolling`）属页面生命周期：控制台页
  `DisposableEffect` 挂卸（方案 §3.1 前台刷新/退后台挂起）。
- **SSE 常连**属内核运行态：页面 5s 轮询 JNI `Gateway.status()` 后经
  `onGatewayRunning(running)` 对齐 —— 内核在跑才连，停机即断，不再依赖
  手工触发；比 M3-1 注释的「与 FGS 同寿」语义等价但实现收敛到一处。
- **事件驱动刷新**：SSE `lagged` → 立即全量刷新；`request_done` → 节流
  2s 合并刷新（流式收尾很密，逐条刷新无意义）。
- **快照韧性**：四个端点独立解析，失败项沿用上一份快照（不闪 0）；
  全部失败才置 snapshotError；向导/KPI 对「从未成功过」（fetchedAtMs==0）
  显示「—」。

### 新手向导完成判据

① 网关运行（JNI status）；② 上游已配置（/health.upstreamConfigured）；
③ 已有真实流量（overview.requests > 0）。三步全过整卡收起（v44 紧凑向导）。

### 基建备注

- **推送通道**：本机（Windows 工作机）直连 github.com:443 被间歇重置，
  push 改走 **Git Data API**（api.github.com 稳定：blob → tree → commit →
  update ref，等价 `git push`）。注意：经此通道落库的文件保留工作副本的
  CRLF 行尾（本地 autocrlf 转换不生效），后续在 Termux 侧编辑会产生一次
  行尾 churn——建议加 `.gitattributes`（`* text=auto eol=lf`）统一。
- **中文过管道会被替换成 `?`**（PS→gh 管道编码缺陷）：81a234c 的提交信息
  因此乱码（保留史痕，不重写历史）；本文档一度落库为 `docs/M3-????.md`
  （Windows git 拒检该路径，`reset --hard` 直接失败）。后续经 API 通道的
  JSON 一律把非 ASCII 转成 `\uXXXX`（全 ASCII 过管道）——本提交即用此
  通道把文件名改回中文。
- **Kotlin 编译坑（首轮 CI 抓到）**：KDoc 内写 `/api/stats/*` 会触发
  **嵌套块注释**（`/*` 吃掉后续全部 `*/` 直到 EOF），报「Unclosed comment」
  并连锁出几十条 Unresolved。文档注释里写路径通配一律避开 `/*` 序列。
- CI 产物 `agate-m0-arm64`（APK + libagate_server.so，27.94 MB）：
  <https://github.com/fxxeng/agate-android/actions/workflows/android-build.yml>
- 版本推进：versionCode 3 / versionName 0.4.0-m3。
